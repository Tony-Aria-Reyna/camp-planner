NZ CAMP PLANNER — PUTTING IT ON A WEB ADDRESS
=============================================

This folder is the whole app. Put it online once and family and friends can open it
on any phone or computer, add it to their home screen, and use it offline.

OPTION A — Netlify Drop (easiest, no code, free)
  1. Go to https://app.netlify.com/drop
  2. Sign up with your email (free).
  3. Drag this whole folder ("NZ Camp Planner (web)") onto the page.
  4. You get a link like https://random-name-123.netlify.app
  5. Optional: Site configuration > Change site name > e.g. "ross-camp-planner"
     gives https://ross-camp-planner.netlify.app
  To update later: open the site in Netlify > Deploys > drag the new folder in.

OPTION B — GitHub Pages (free)
  1. Create a free account at https://github.com and a new public repository, e.g. "camp-planner".
  2. "Add file > Upload files", drag in everything in this folder, Commit.
  3. Settings > Pages > Source: "Deploy from a branch", branch "main", folder "/ (root)", Save.
  4. After a minute the link is https://YOUR-NAME.github.io/camp-planner/

INSTALL ON A PHONE
  iPhone (Safari): open the link > Share > Add to Home Screen.
  Android (Chrome): open the link > menu (three dots) > Install app / Add to Home screen.
  It then opens full screen like an app. Map areas you have looked at stay available offline.

GOOD TO KNOW
  - Each person's sites, trips, routes, journal and photos are saved on their own device,
    not on the website. Nobody can see anyone else's plans.
  - The web version and the HTML file on your computer keep separate data. To move your
    plans across, use 6 · Data > Create transfer code in one and Restore in the other.
  - To share a single trip with someone, use 3 · Trips > Share this trip. They paste the
    code into 6 · Data and it is added to their trips.
  - The link is public to anyone who has it, so share it with the people you choose.
